📘 Abstract

This project implements a real-time hand landmark detection and finger counting system leveraging Google’s MediaPipe AI. It tracks 21 hand landmarks to accurately count fingers, enabling applications such as gesture control, sign language interpretation, and enhanced human-computer interaction right in your web browser.

🎯 Key Features

  • Real-time detection of hand landmarks with 21 key points directly in the browser
  • Accurate finger counting using landmark geometry comparisons
  • Robust multi-hand tracking with MediaPipe’s ML pipeline
  • Zero latency: Processes video securely on your device without sending images to a server
  • Responsive UI and lightweight design compatible with standard laptops and mobile devices

🧰 Technologies Used

MediaPipe JS Python Flask (Serving) HTML5 Canvas CSS3 JavaScript

💡 Applications

  • Touchless gesture control interfaces
  • Sign language translation systems
  • Virtual Reality (VR) and Augmented Reality (AR) interaction
  • Assistive technology for differently-abled users
  • Gaming and interactive media control

⚠️ Limitations

  • Detection accuracy can drop in low-light or cluttered backgrounds
  • Difficulty tracking overlapping or multiple hands simultaneously
  • Dependent on webcam quality and frame rate

🚀 Future Scope

  • Adding complex gesture recognition and classification
  • Multi-hand simultaneous detection and tracking
  • Integration with voice and eye-tracking systems
  • Deploying mobile and embedded system versions
