📘 Abstract

This project implements a real-time hand landmark detection and finger counting system leveraging OpenCV and Google’s MediaPipe. It tracks 21 hand landmarks to accurately count fingers, enabling applications such as gesture control, sign language interpretation, and enhanced human-computer interaction on standard webcams.

🎯 Key Features

  • Real-time detection of hand landmarks with 21 key points
  • Accurate finger counting using landmark comparisons
  • Robust hand tracking with MediaPipe’s ML pipeline
  • Flask-powered web interface for live streaming and count display
  • Responsive UI and lightweight design compatible with standard laptops

🧰 Technologies Used

Python OpenCV MediaPipe Flask HTML5 CSS3 JavaScript

💡 Applications

  • Touchless gesture control interfaces
  • Sign language translation systems
  • Virtual Reality (VR) and Augmented Reality (AR) interaction
  • Assistive technology for differently-abled users
  • Gaming and interactive media control

⚠️ Limitations

  • Detection accuracy can drop in low-light or cluttered backgrounds
  • Difficulty tracking overlapping or multiple hands simultaneously
  • Dependent on webcam quality and frame rate

🚀 Future Scope

  • Adding complex gesture recognition and classification
  • Multi-hand simultaneous detection and tracking
  • Integration with voice and eye-tracking systems
  • Deploying mobile and embedded system versions
